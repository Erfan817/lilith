# 紫微斗数：四化表、来源天干与时间层次

本页为原创说明，重点是区分已经提供的四化与尚未计算的层次。四化是传统盘式中的天干—星曜对应标记，不是独立天体，也不是测得的心理或物理能量。它们可以支持文化性的讨论，但不能证明何时升职、发财、结婚、患病或发生灾难。

## 一、四化分别可以讨论什么

**化禄**：传统关联增加、吸引或所得。本模块先问增加了什么、由谁承担成本，不直接等同到账收入。资源、邀约和任务都可能增多，是否有益取决于用户需要与真实条件。化禄不同于独立辅星禄存，数据里不可把两者合并。

**化权**：可讨论主动承担、执行、权限与责任。不是官职保证，不给人控制他人的正当性。关系主题里出现权，可问怎样分配决定与劳动，而不是认定对方性格强势或必须服从。

**化科**：传统涉及表达、识别、名誉或支持，可讨论清楚呈现与获取合适资源。不是考试必过、贵人必来或病灾被解除的证据；被看见也可能有成本，不能把科当“免疫失败”。

**化忌**：可以讨论执着、阻碍、未满足需求或反复关注。不能由一个忌字断灾难、失败、死亡、贫穷或关系破裂，也不把所有真实困难仅仅说成“你内心太执着”。现实约束同样需要被承认。

这些都是新写的反思表达，不将任何四化固定作人格诊断。即使同一颗星受到不同四化，也不意味着用户变成另一种人；具体含义须放回宫位、层次和用户事实。

## 三、四化从哪一层来

### 生年或本命四化

根据来源所采用的出生年干挂在真实存在的主星或辅星上；它属于本命盘资料。可以作为长期主题的文化线索，但不说一生固定财运与性格。需知道年界是农历正月初一、立春还是其他明确口径，不能暗用另一个系统的年干。

### 大限四化

常见以大限所在宫干起四化，但具体定义和运限映射须由外部盘或规则说明。大限宫干不是直接等同这十年的公历年份干；不知道当前大限宫与宫干时不得补算。阶段主题仍不意味着每天都会发生同一类事件。

### 流年四化

在所选年界下由该流年天干产生四化，结合本命与大限参考。它与本命四化可能作用在同一颗星上，但来源层不同；数据不能只写“星化禄又化忌”却丢掉分别来自哪个干。也不能把当年全体人在此表下共用的四化名单当成所有人具有相同结果。

### 宫干飞化

某一宫的宫干产生四化，附着星实际在哪宫就形成从源宫到落宫的关系。这是飞星等体系的额外读法，不能在以星曜三方四正为主的报告里暗中混用。至少需要完整宫干、四化表、各星真实落宫及流派对自化、对宫冲等的定义。

### 流月、小限与更细层

小限与流年不是同一张盘，流月也不是将流年关系简单缩小到某月就完成。没有真实外部资料及对应规则时不进一步安宫、挂化或报日期。看得更细不自动更准确，输入误差和解释选择可能更大。

## 四、建议的数据结构

这是一条四化标记的字段骨架，未知保持空值，不是计算结果。

```json
{
  "kind": null,
  "star": null,
  "source_scope": null,
  "source_stem": null,
  "source_palace": null,
  "target_palace": null,
  "target_branch": null,
  "sihua_table_id": null,
  "source_artifact": null,
  "verified_against_source": false
}
```

`source_scope` 应区分 natal、decadal、annual、palace 等层；值只是记录标签，不因填写英文就代表已实现接口。生年四化可能没有源宫，宫干飞化则必须有。附着星没有在原盘出现时不能擅自补星，要检查是否漏了文昌、文曲或左右等辅星，或是不是表口径不一致。

如果一宫同时有禄与忌，要说明是两颗星各一化、同星跨层，还是来源中的宫干飞化。相同字的重复不能按个数放大命运，例如“双忌就是损失两倍”没有可验证根据。记录层次，远比加出一份看似精确的分数有用。

## 五、时间层的常见规则与边界

大限通常以一宫十年作为阶段，并由五行局决定常见起限年龄：水二局从二，木三局从三，金四局从四，土五局从五，火六局从六开始。传统常见顺逆为阳男阴女顺、阴男阳女逆；这里的男女是传统计算参数，阴阳是相应年干类别。现实身份不能由模型猜，具体年龄范围、虚岁还是周岁都需外部盘确认。本页讲概念，不计算用户正在走哪一限。

流年命宫常见按当年地支落宫，另有流月、小限等方法；不同规则的结果不能拼成一张没有来源的盘。原盘若显示大限起止，先沿用并注明年龄口径，不能仅以用户现在的周岁去猜盘中的虚岁所在阶段。

出生年的界点、流年界点、流月的定干以及小限年龄界点可能由软件分别配置。已读取 iztro 文档展示本命年界、运限干支界、年龄分界和晚子时归属等可配置项，说明同一生日在不同设置下并非所有字段都相同。本模块不能用一句“默认北京时间”就掩盖这些差异。

闰月出生需同时记录实际是否闰月与派别采用怎样的月份归属；闰月流月的解释另需来源说明。真太阳时、民用时及跨时辰误差会先影响命盘底层，不能等到“断不准”才回头换生时。边界附近先看候选盘差异，不根据用户某个经历选符合期待的一张。

## 六、固定叠看顺序

先把本命主题作为原材料，再看真实大限的阶段范围和宫名映射，然后看目标流年，最后才讨论有资料的流月或小限。每次叠加都标明“这是哪一层的命宫、财帛宫或四化”，避免同名宫在不同层被混成同一位置。

在用户主题宫中，先列主星与三方四正，再读已经核实的四化。若讨论禄，问实际资源从哪里来、如何使用；讨论权，问权限与责任是否匹配；讨论科，问怎样清楚呈现、谁能提供合适支持；讨论忌，问什么具体限制可核实、哪些担忧还只是想象。动作来源于现实问题，而非从吉凶字面下命令。

跨层同星或同宫集中，可以讨论某一主题被多次提出，但不把重复当三份独立命运证据。矛盾符号可描述资源与成本并存，不自动判“先好后坏”。最终给开放情景和需要核实的条件，不报未经计算的具体月份、结婚年龄或收益区间。

## 七、飞入、自化、忌冲：限制好术语的权限

“源宫飞某化入目标宫”说明一套传统对应下的关系，不证明现实 A 一定爱、害或控制 B。自化通常涉及本宫干所化星在本宫等判定，不同支派对向心、离心、箭头方向等还有区别；必须读取来源图例和规则，不能凭一个箭头朝外就任意命名。

忌在对宫被称为冲某宫的传统读法也不意味着该宫人物遭殃。解释可以转成需要协调的期待或限制，不能断配偶不忠、父母短命、孩子有问题。没有宫干和飞化原资料时，只讲定义，不生成飞线，也不把情绪反馈当作真实自化条件。

## 八、应期不确定性与现实核实

这套文化参考不能给经统计校准的事件概率。“某年更容易出现主题”的措辞若没有盘层和现实迹象，仍会让人误以为预言，应改为“在这份传统读法中，可以把该年用作检视这个主题的日记窗口”。若用户需要具体现实日期，依据报名截止、项目进展、医疗安排或法律期限，而不是编造四化应期。

真正可核实的是用户采取了什么动作、获得什么新信息、哪种解释不适用。不要只保留“似乎命中”的事例。复盘若发现输入或设置错误，直接更正，说明受影响层次；不把错盘合理化为流派神秘性。

## 九、输出前检查

- 所有四化都注明类型、附着星、来源干、来源层与表版本。
- 本命、大限、流年的宫名映射分开，不把源宫与落宫颠倒。
- 闰月、换日、年界、时间校正、年龄口径与输入误差已列出或明确未知。
- 没有自称本地安星、编造生日、制造精准应期或补造流派全表。
- 不用禄权科保证成功，也不用煞忌恐吓失败、死亡或道德缺陷。
- 现实高风险事项交可靠渠道，文化解释只提供可拒绝的反思空间。
