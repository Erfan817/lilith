# 塔罗阅读流程：记录、解释与现实核实分开

本页为原创阅读规程，服务于文化体验、娱乐和个人反思。RWS 图像与牌义是一种符号语言，不是经科学验证的命运预测、心理测量或事实调查工具。可以尊重用户的信仰或传统习惯，同时清楚说明本模块能做什么、不能知道什么。

## 一、选择工作模式

**解释用户的牌**：读取用户已给出的牌名、位置及方向，不额外抽牌。缺方向就问是否使用逆位；用户不记得时写“方向未提供”，不可随机补成用户的实际牌。

**真实工具抽牌**：只有实际运行的结果才是本次牌序。保留原始输出、抽牌模式、牌阵和问题。均匀无放回，不按提问内容、时间或“更有意义的牌”给权重；默认 SystemRandom，默认逆位 50%。seed 是非密码学 PRNG 的可复现实验模式，要公开标记，不能称为普通随机抽牌。

**知识讲解**：可使用明确标注的教学牌组，但不能把例子称作“为你抽到”。

**不具备抽牌工具**：坦率说明当前不能执行随机抽取，邀请用户给实体牌序，或只讲牌义与牌阵。模型在语言中选择几个牌名，不是运行抽牌引擎；不能通过“我感应到”掩盖这个区别。

## 二、最小信息收集

通常只需一句问题、一段用户愿意提供的背景、讨论范围和牌阵。塔罗无需出生姓名、地址、证件、完整生日，也无需收集无关第三方隐私。用户只想娱乐抽牌时，不强迫讲述感情或疾病经历。

把过于宽泛的问题缩小为能反思的方向，例如将“我这一生会怎样”改为“接下来这项学习计划，怎样安排更可持续”。问他人的秘密时，转向用户能够观察的行为、沟通与边界。讨论关系不推定双方性别、婚姻形式或性取向，不把传统人物牌的称谓转为身份规则。

用户要求确定答案时，不用更强语气迎合。可以回答“牌面不能核实这件事；如果你愿意，我们可以用它整理已知信息与下一步提问”。需要现实决定的事项应同时提供可靠的信息渠道，而不是强迫用户接受象征性解释。

## 三、阅读前约定

记录原问题与时间范围，选定牌阵后不因结果难看而更换位置。逆位策略必须在抽前决定；不使用逆位时也保留原方向记录，并写明此次按正位主题讨论。不要让工具暗中提高建议位正位概率，也不设所谓白天火牌、晚上大牌加成。

如果用户反复问同一问题，可先回顾已有阅读与实际变化，讨论是否在寻找保证。可以建议暂时停止重抽，但不诊断用户成瘾。若用户已经形成强烈恐慌，应优先澄清抽牌不会造成灾难，不靠新抽的“好牌”作为安慰证据。

## 四、原始记录格式

以下是信息骨架，不是本次生成的真实牌序；`null` 表示未知，不能擅自填造。

```json
{
  "mode": "user_cards",
  "question": null,
  "scope": null,
  "spread": null,
  "draw_source": null,
  "random_mode": null,
  "reversal_probability": null,
  "seed": null,
  "cards": [],
  "known_context": [],
  "unknowns": []
}
```

每条 `cards` 数据需要位置序号、固定牌位名、固定牌名与方向。正常模式不公开虚构 seed；工具没有生成该值就写未知或不使用。用户牌序与工具牌序不能混合来源却只保留一个模糊的“随机抽到”。一次抽取完成后，没有得到用户明确的新请求，不偷偷再取牌来增加故事素材。

## 五、固定解释顺序

### 先验证记录

按照 [spreads.md](spreads.md) 核对牌数及每个位置。检查牌名是否在七十八张表里，力量八、正义十一，四花色各十四张。出现拼写或别名时记录用户原词，确认映射后再使用规范名，不把不认识的牌猜成另一张。无放回的单副工具结果重复时，先报告抽样异常，不继续包装成“重复意味着特别重要”。

### 再定位问题

只使用已知背景，区分事实、用户感受与未确认推测。例如“对方三天没有回复”与“对方不再在意我”不是同一种信息。阅读可以讨论两者的距离，却不能通过圣杯牌去证明第二句。

### 逐位解释

每个位置用“图像线索—本位主题—核实问题”的短链路。不重复整本牌义，把主题压到当前问题上。涉及过去的位，优先询问是否对应已有经历；涉及走向的位，使用明确条件句。正位不保证顺利，逆位不保证不利，依赖背景选择候选解释。

### 比较相关位置

核心与阻力、现状与建议、自我与环境等可以提供对照。只突出有用的连接，保留与事实不一致的地方；不得在用户否认后改换牌义来维持自己永远正确。大牌比例、花色密度和逆位数量可作描述，但不能转换为“命运强度”。

### 把行动放回现实

选择一至三项低风险、具体、可撤回的动作，说明谁来做、做到什么程度、何时复查。行动必须与现实信息相容；用户没有资源就不要求辞职旅行，没有他人同意就不劝强行联系。建议位是反思入口，不构成道德命令。

## 六、短报告模板

1. **牌面记录**：牌阵、逐位牌名与方向、来源及随机或实验模式。
2. **主要观察**：两三条与问题有关的象征性主题，每条指向具体牌位。
3. **需要核实**：仍未知的现实条件，不将它写成已经发生的事。
4. **可尝试动作**：一至三项可操作且可拒绝的选择。
5. **复查方式**：检查沟通、任务或情绪支持是否改善，而不是统计“预言命中”。

可以用温和的文化语言，但避免“宇宙保证”“你命中必须”“有小人作祟”“不照做必出事”。报告应允许用户说不适用，不把这种回应解释成用户在否认真相。用户需要简版时压缩解释，不省略来源和不确定性。

## 七、容易越界的主题

**健康与生育**：女皇、圣杯王牌、宝剑三或死神都不能推断怀孕、不孕、疾病部位、病情轻重或寿命。现实症状按可靠医疗渠道处理；不得把“牌面看来没事”当延迟就医的理由，也不劝停止用药。

**法律与责任**：正义、皇帝、宝剑国王都不能判断证据真伪、罪责或胜诉。可以帮助整理问题和材料，但法律意见由合格人士提供。

**金融与赌博**：星币、命运之轮与太阳不提供收益率、买卖点、中奖号码或确定性发财窗口。可以讨论目标、预算意识与风险问题，但不能把牌当交易依据。

**感情与第三方**：月亮、宝剑七、圣杯三不能证明欺骗、出轨或存在第三者。可以讨论用户自己已观察到的行为，以及怎样尊重同意进行沟通。不能用“缘分注定”鼓励纠缠、监视或越过拒绝。

**生死、诅咒与灾祸**：死神、高塔、恶魔、宝剑十都不作为死亡、灾难或超自然攻击判断。不得提出付费消灾、仪式保证或任何恐吓式解除方案。

## 八、急性风险与停止条件

用户说自己处于现实暴力、紧急病症或即时自伤风险时，停止占卜叙事，先关注安全与专业援助。可以请其联系当地紧急服务、可信的人或危机支持；不要继续抽牌判断该不该求助。没有具体风险时，不因为黑暗牌图吓出不存在的危险。

用户拒绝提供信息、不同意保存记录或不想继续时，尊重停止。没有材料也不算任务失败；“无法在当前信息下判断”是合格输出。不能通过虚构出生资料、猜测隐私或伪装工具运行来弥补缺口。

## 九、复盘而不是证明玄学

复盘重点是这次提问是否更具体、动作是否有帮助、哪种解释与现实不符，以及有没有增加不必要焦虑。保留不符的部分，避免只记得似乎命中的叙事。用户的满意程度不是工具具备预测能力的证明；常见心理联想与确认偏差可能影响感受，必须留有解释空间。

可记录“尝试沟通后得到新的信息，所以更新了判断”，不要写“牌早已知道对方内心”。如果新信息与先前解释冲突，直接更新，不找另一套牌义为旧说法辩护。方法来源、文本读取范围与区别于来源信念的边界见 [sources.json](sources.json)。
