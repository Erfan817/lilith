# 塔罗牌阵：六种固定接口与解释范围

本页是 莉莉丝（Lilith） 的原创牌阵参考。牌阵是为问题划分观察位置的约定，不是可以检测命运的仪器。排列方式没有唯一历史标准；下面固定的是本项目与抽牌记录共用的名称、顺序和牌数。Waite 的凯尔特十字资料仅帮助核对这个传统牌阵的结构，本项目的时间位名称和阅读边界属于明确的当代改编。

## 接口总表

| key | 中文名 | 牌数 | 位置顺序，必须逐字保留 |
|---|---|---:|---|
| `single` | 单张 | 1 | 当前指引 |
| `three` | 三牌 | 3 | 过去 / 现在 / 可能走向 |
| `diamond` | 菱形五牌 | 5 | 核心 / 根源 / 阻力 / 潜力 / 建议 |
| `moon` | 月亮四牌 | 4 | 新月 / 上弦 / 满月 / 下弦 |
| `horseshoe` | 马蹄七牌 | 7 | 远期过去 / 近期过去 / 当前 / 近期走向 / 外部影响 / 建议 / 可能结果 |
| `celtic` | 凯尔特十字 | 10 | 核心 / 交叉 / 意识目标 / 根基 / 近期过去 / 近期走向 / 自我 / 环境 / 希望与恐惧 / 可能结果 |

本页中的“过去”用于回顾已知经历，不授权补造事件；“可能走向”和“可能结果”表示在当前讨论假设下的开放情景，不是将发生的事实。不能把用户没有提供的生活背景强塞进相应位置。实际抽牌记录若位置不同，应先报告接口不匹配，不擅自挪牌来配合故事。

## 抽牌前必须确定的五件事

一是要讨论的单一问题，尽量写成“我可以如何理解或应对这件事”，而不是要求知道未同意参与者的秘密。二是讨论范围，例如下一阶段的沟通，而不是从一张牌断一生。三是牌阵与各牌位含义；如要自定义，只能抽牌前共同确定，并明确不是下面的固定接口。四是是否使用逆位。五是抽牌来源：用户给出的实体牌序、真实工具结果或明确标注的教学示例。

正常工具抽牌的约定是七十八张等机会、无放回，默认 SystemRandom；每张的正逆位分别按 50% 概率选取，不根据时段、问题文字或“重要牌位”改变权重。seed 模式只能用于公开标记的可复现实验，使用非密码学 PRNG；不能把 seed 结果宣称为正常随机，也不能为了抽到满意答案反复换种子。此页定义接口而非提供脚本，是否有可运行工具应以实际工具输出为准。

## `single`：单张

### 位置

1. **当前指引**：本次反思最值得先处理的一个角度。可讨论观察、提问或小动作，但不是一天里所有事情的总预报。

### 怎样读

先说牌名和方向，再描述一处图像线索，把它连接到用户已经说过的困境；提出一个核实问题，最后给一项低成本动作。因为只有一个位置，不足以构造复杂因果、其他人的性格或完整时间线。若用户的主题本身包含多个互不相关的问题，应先挑一个，而不是用单牌覆盖全部。

### 适用与限制

适合写日记、开始一项任务前的注意事项、结束一天后的复盘。用户只是想抽一张做娱乐时，可以不追问大量私人资料。单牌不能回答怀孕、寿命、投资胜率、罪责认定；这不是牌数不足而可以通过加牌解决的问题，而是整个工具不具备这种现实证据能力。

## `three`：三牌

### 位置

1. **过去**：用户确认的先前条件、处理习惯或已经发生的经验。
2. **现在**：目前可见的状态、需要和张力。
3. **可能走向**：延续现有条件时可以讨论的一种发展情景。

### 固定解读顺序

先读第二张定位当下，再读第一张检查已有经历能否提供解释，最后读第三张提出开放情景；成文时仍逐位列出原始顺序。第三张应有条件句，例如“如果继续用目前沟通方式，值得留意……”。没有给过去资料时，第一张转为“可以回顾的角度”，不得声称看见某年发生过什么。

比较第一张与第二张时，讨论变化而非自动判断谁导致了谁。第三张并非前两张的数学结果，也不表示故事只能如此。若要采用“情况—行动—反馈”的三牌方案，应在抽前自定义说明；不能把该方案和固定 `three` 的三个位置混用却维持同一个记录。

## `diamond`：菱形五牌

### 位置

1. **核心**：本次问题最主要的矛盾或需求。
2. **根源**：已知背景、习惯或资源条件的观察线索，不能据此编出童年创伤。
3. **阻力**：妨碍推进的因素；逆位或不悦图像不是“有人害你”的证据。
4. **潜力**：可以发展的资源或新视角，不保证一定实现。
5. **建议**：与现实条件相容的一项小动作。

可用一张在中心、第二张上方、第三张左方、第四张右方、第五张下方的摆法；图形只帮助记住位置，抽牌接口以序号为准。

### 固定解读顺序

先读核心，再并读根源与阻力，接着读潜力，最后读建议。把建议与阻力做一次相容性检查：若阻力是过载，建议不能机械变成“再做更多”；若阻力是信息不足，潜力应落实为获取信息，而不是凭信心冒险。根源可与核心形成一个待验证的解释，却不意味着从牌面得到真实因果关系。

### 适用与限制

适合目标梳理、创作困境、非紧急的人际沟通。五牌能展开资源与障碍，但不能给出“成功概率”。行动位必须允许拒绝；面对用户的现实限制，修改动作而不是责怪用户没有执行牌的指示。

## `moon`：月亮四牌

### 位置

1. **新月**：开始的意图，想建立什么。
2. **上弦**：推进中的选择与练习，哪些事情需要实际完成。
3. **满月**：观察到的反馈、需要看见的成果或矛盾。
4. **下弦**：结束本轮时的整理、释放与保留。

### 固定解读顺序

按四个位置依次阅读，然后把第四张与第一张连接，检查本轮学习如何影响下一次开始。这是用月相作比喻的反思循环，不是星历工具，不需要编造当天的真实月相。没有读取天文资料时不得宣称“今晚满月，因此牌更准”，也不把塔罗的月亮牌和牌阵的满月位置混为一谈。

### 适用与限制

可以用于一个创作周期、习惯实验或项目迭代。用户可以指定自己的起止日期，但日期只是日记与行动安排，不会让抽样受到天体“增幅”。讨论生理周期、怀孕或心理症状时只保留非医学反思，不利用月相作诊断或预测。

## `horseshoe`：马蹄七牌

### 位置

1. **远期过去**：较早的、用户已确认的背景。
2. **近期过去**：最近发生并影响当前的事实或选择。
3. **当前**：眼前状态与主要需要。
4. **近期走向**：下一阶段的条件性情景。
5. **外部影响**：已经可见的资源、流程与关系条件；看不见的他人意图仍是未知。
6. **建议**：可在现有条件下尝试的行动。
7. **可能结果**：在背景、限制及行动假设下的一种反馈情景。

常见摆法是把七张由左到右排成弧线；高低与左右并不改变位置意义，线上呈现可直接使用有序列表。

### 固定解读顺序

先用第三张锚定当前，第二张与第一张按近到远检查背景，再读第五张的外部条件，第四张讨论走向，第六张形成动作，第七张给出条件性结果。不要把第三、第四、第五张读成“现在—未来—未来中的某人”而丢掉第五张的外部条件属性。

行动改变后，可能结果自然也可能改变。报告不应拿“结果位”否定此前的可用资源，也不能对用户说建议没执行就会遭遇某种惩罚。缺乏现实背景时，可以逐位给反思问题，但不能依次编出一段完整传记。

## `celtic`：凯尔特十字

### 位置

1. **核心**：当前主要处境。
2. **交叉**：与核心相交的因素，可以是支持与要求，也可以是障碍。
3. **意识目标**：当事人已经表达或愿意讨论的目标。
4. **根基**：既有条件、习惯、资源或背景。
5. **近期过去**：最近可核实的进展。
6. **近期走向**：延续目前条件时的一种近程情景。
7. **自我**：当事人可以反思的立场与行动姿态。
8. **环境**：已知外部流程、关系及资源。
9. **希望与恐惧**：期待与担忧的张力，二者不等于事实。
10. **可能结果**：在当前假设下的一种开放结局。

实体摆法可将第一张放中央、第二张横跨其上，第三张在上、第四张在下、第五张在左、第六张在右；第七至第十张从下到上排在右侧。第二张横放只是布局，不决定其逆位；正逆位应来自真实抽牌记录。若采用其他地区的十字摆法，保留本项目牌位顺序，别以图形左右自动改含义。

### 固定解读顺序

先并读核心与交叉，确认主题而非将交叉一律说成敌人。接着比较意识目标与根基，再看近期过去与近期走向。读自我、环境、希望与恐惧，分清自主选择、外部限制与主观担心。最后才读可能结果，并检查它是否与已经确认的条件相容。

十字的价值在于区分层次，不在于叙事更戏剧化。根基不自动等于潜意识，也不授权诊断用户创伤；环境不等于透视他人心意；希望与恐惧必须以提问方式开放给用户，而不是把想象变成预告。抽牌前未选代表牌时，不额外增加一张人物牌当身份牌；固定接口是十张，不偷偷变成十一张。

## 通用自查

逐位核对原始记录里的牌数、牌名、方向与顺序。无放回抽样不应出现同一张牌两次；用户使用多副实体牌或手动列出重复时，先说明与单副工具规则不同。大牌多、某花色集中或逆位多，只表示本次符号分布，不代表事情重要程度、命运强弱或危险指数。短牌阵里没有某花色尤其不应被说成“人生缺失这种能力”。

解释完成后提供一个复查点，让用户观察动作有无帮助；不要求为了“验证”连续重抽。只有问题、事实条件或讨论目的真正改变才考虑新阅读，并保留旧记录，不把不合意的结果删除。细化流程见 [reading.md](reading.md)，关系比较见 [relations.md](relations.md)，知识来源见 [sources.json](sources.json)。
