# 月亮交点：几何轴线、不同传统与非宿命读法

> 原创中文整理；原创表达适用本项目 MIT，来源文章和图像不重新许可。交点的轨道几何可计算；成长、熟悉模式、业力等是不同占星传统的解释，不是天文学证明。本文不宣称覆盖印度占星、演化占星或所有西方交点方法。

## 1. 交点究竟是什么

月亮绕地球运行的轨道平面相对黄道平面有倾斜。两个平面的交线在天球上给出一组相反方向：月亮从黄道南侧转向北侧的交会方向为**升交点或北交点**，从北侧转向南侧为**降交点或南交点**。这里的北与南是相对黄道，不是出生地的地理南北，也不是简单等于赤纬北南。

常用符号为北交点 `☊`、南交点 `☋`。龙头、龙尾是历史命名，印度的 Rahu、Ketu 还有自己的神话与技术系统；翻译名称并不使这些系统完全一致。交点不是有质量、会发光的行星，不存在“交点对地球的引力造成性格”这一基础解释。

同一模型下两点构成对轴，南交点可由北交点黄经加一百八十度后归一化得到。若一份结果两点并非相对，先检查是否混用了真与平均模型、日期或黄道口径，而不是把误差当成特殊命盘。

## 2. 平均交点与真交点

**平均交点 Mean Node**采用平滑化的轨道长期变化模型；**真交点 True Node**通常保留某类短期变化或瞬时轨道信息。具体“真”算法仍需查看星历说明，不能把这个名字理解成只有它正确而平均模型虚假。两者都在表达轨道的不同计算口径。

平均交点以长期逆行的形式运行；真交点会因短期变化在某些时段出现顺行。不同模型的黄经可能在星座或宫位边界附近给出不同归属，精确相位也可能变化。报告必须注明模型，不用另一个模型的度数来解释本模型的相位。

交点轴长期绕黄道退行的周期约十八年半，这只提供粗略周期尺度。准确回归、反向交点联系或与某天体成相的时刻仍须用真实计算求解。不能把“某岁”写成所有人的固定事件日，也不凭两个周期巧合宣称轮回证据。

基础实现若只输出平均交点，就应明确标注为平均交点；若没有交点实现，知识介绍不等于生成了实际位置。未给出真实位置、地点或可靠时间时，不声称知道交点落宫。真交点与平均交点、恒星黄道偏移和宫制都要分别说明，不能合并为一个选项。

## 3. 与日月食的关系

由于月亮轨道倾斜，并非每次新月都有日食、每次满月都有月食。日月在交点附近形成适当的新月或满月几何，才可能发生对应的食。食的具体可见范围、类型及精确时刻还依赖三维位置、距离、影锥与地表地点，不能用黄经容许度表完全替代。

日食涉及月亮遮挡太阳的视线，月食涉及地球阴影投向月亮。此天文学关系是交点有实际几何意义的理由，不证明“食季必有个人灾难”。报告食相主题时，把天文事件、所用占星象征及当事人现实情况分开。

相位表中的合相并不等于实际掩食。黄纬、视差和距离会改变真实对齐，给两个黄经在八度之内就宣布正在发生日食，是将占星阈值误当物理判据。观察太阳还应遵守安全观测规则，不能直接看太阳作为“连接能量”的练习。

## 4. 西方历史解释并非只有一条

某些中世纪西方解释把北交点联系增加、南交点联系减少，或北偏吉、南偏凶。增加本身不一定有益：增加资源与增加冲突不同；减少负担与减少支持也不同。不同历史作者对交点如何改变吉星和凶星的作用有分歧。

因此本项目不采用“北交点永远最好、南交点永远最坏”这一统括结论，也不把某一作者的经验声称转写为事实规律。若以传统口径阅读，应先说明是增加减少、吉凶、与月亮纬度周期的联系，还是只看紧密合相，并保留方法差异。

所读取的 Joseph Crane 文章提出以月亮性质、冷热干湿和弯点重新理解交点，是一个具体作者的现代研究观点，不是所有传统共同认可的定理。可以介绍其思路，但不能在本项目里无标记地当作古典标准。

## 5. 常见现代心理读法

现代常把南交点理解为熟悉、已形成或容易回到的模式，把北交点理解为尚需练习、较不熟悉的方向。这是一种象征性工作框架，而不是对过往人生的客观测量。南交点可能指可利用的经验，也可能指过度依赖；北交点可能提供新选择，也可能被理想化。

**整合优于迁移。** 阅读不应要求完全丢弃南端、永久住在北端。比如从“只靠自己”练习“适度合作”，不是否定独立能力，而是增加情境选择。若某人已经具备双方能力，不用另造隐藏的灵魂阻碍来保证叙述永不被否定。

需要避免三类绝对语言：前世职业或罪责；今生唯一使命；未走向北交就会受罚。即使用户愿意谈轮回，也把它明确称为信念语境中的象征，不作为已查明历史。不得诱导记忆，不把贫困、疾病或受害经历说成业债。

## 6. 星座轴线：六组提问而非十二种命令

由于交点互为对点，一张盘总有一组星座轴。下列是原创的生活反思结构，可以双向使用；应先写哪一端是北交，哪一端是南交，不默认为表格左端永远是成长方向。

| 星座轴 | 两端可以讨论的功能 | 可检验的整合问题 |
| --- | --- | --- |
| 白羊—天秤 | 自主启动与关系协商 | 你能否既说出自己要什么，也听清对方可以接受什么？ |
| 金牛—天蝎 | 保持稳定与面对共享、变化 | 哪些资源适合自己维护，哪些必须透明协作并允许调整？ |
| 双子—射手 | 具体信息与整体意义 | 你能否查细节又保持方向，遇到反例是否修订信念？ |
| 巨蟹—摩羯 | 照顾归属与长期结构 | 责任安排是否支持真正的需要，而不是相互替代？ |
| 狮子—水瓶 | 个人表达与共同原则 | 你能否有自己的作品和立场，同时给他人同样空间？ |
| 处女—双鱼 | 区分落实与回应整体 | 你能否形成具体步骤，也允许感受和未知暂时没有答案？ |

这些主题不是两个相对星座的道德比较。金牛不只有物质，天蝎不只有放弃；狮子不只自我，水瓶不只集体。应从具体生活材料出发，避免选择性读取一端所有负面词、另一端所有正面词。

## 7. 宫位轴线：具体场景要与星座分开

宫位描述实践在哪里发生，而不是怎样发生。北交点在白羊不等于北交点在第一宫；第一宫不是白羊。出生时间不可靠时，可能保留交点星座，但不能给出确定宫位轴。

| 宫位轴 | 可讨论的具体场景 |
| --- | --- |
| 一—七宫 | 自我呈现、主动选择与明确的伙伴协商 |
| 二—八宫 | 个人可支配资源与共享义务、借贷、税务 |
| 三—九宫 | 日常消息、附近学习与系统知识、异文化视野 |
| 四—十宫 | 居住与私人根基、公开角色与责任 |
| 五—十一宫 | 自发快乐、作品与团体目标、朋友支持 |
| 六—十二宫 | 维持运行的劳动、休息退隐或受限处境 |

假设交点在三—九宫轴，现代心理框架可以问信息与大图景如何平衡；不可以立刻断言要出国或成为教师。整宫与等宫的边界不同，交点在两种宫制中的归属可能变化，应如实标注。

## 8. 与行星合相、对分和四分

若一个天体合北交，便同时对南交；合南交也同时对北交。它们描述同一轴线关系，不是两条互相独立的证据。同一天体对两端成四分，也属于同一轴的联系，不把“双重四分”当更坏的自动评分。

本篇人工阅读建议先看较紧联系，例如合相、对分与四分三度内；有些作者使用两度，有些五度。**这不是统一标准，也不表示基础脚本自动采用这个阈值。** 必须给出实际偏离和交点模型，不能只写“命运相位”。

水星接触轴线可提问信息习惯与新学习的配合，金星可提问关系与价值模式，火星可提问争取与拒绝方式，土星可提问规则和责任。不要把任一合相强行解释成某个天体“带来前世”，也不因外行星接触交点就宣布关系不可逃避。

## 9. 弯点 Bendings 及优先级

历史与某些现代技术关注在黄经上距交点轴约九十度的联系，称弯点。需区分两个对点及所用方向口径。月亮真实最大黄纬附近的轨道问题，也不能完全由任一行星对交点黄经成四分代替。

弯点可以作为进阶阅读的背景，但不应盖过日月、四轴、宫主和个人天体的主要结构。没有真实交点、准确度数或清楚规则时，不用弯点补出一段似是而非的精密解读。本知识库说明它存在，但不声称已经实现每种纬度或弯点算法。

## 10. 交点、莉莉丝与凯龙不是同一个对象

本项目品牌名称“莉莉丝 Lilith”不等于盘上必有某颗同名行星。占星中所谓黑月莉莉丝通常与月亮轨道远地点的计算有关；还存在小行星 Lilith 及其他历史假想点，必须按具体对象和模型区分。不能把它当成月亮交点，也不因品牌名就自动把该点纳入所有盘。

凯龙是实体小天体，交点是几何点；它们的资料来源、星历及解释范围不同。没有可靠凯龙星历时不提供虚构位置，黑月莉莉丝也不在本篇交点算法中替代或暗示支持。详细天体范围参见 `planets.md`。

## 11. 非宿命的实践步骤

先确认数据与模型；再读一组轴及与其紧密联系的天体；明确采用传统或现代心理框架；提出一至两项情境问题；收集支持和反例；选一个安全、可回顾的行为练习。例子可以是协商边界、补充学习、透明预算，不是改变人生来迎合一段解释。

记录包括日期、情境、实际行为、结果、替代解释。若当事人说不符合，允许保留为不符合。不能说“你尚未觉醒所以感受不到”来逃避检验。这样的生活记录只能提高解释的诚实程度，不能作为占星理论整体被科学验证的结论。
