## 地支关系

### 六冲
子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲

### 三合局
- 申子辰合水局
- 亥卯未合木局
- 寅午戌合火局
- 巳酉丑合金局

三字齐全是三合组合的形式条件，不保证自动合化。申子、子辰等常称半合；缺中神的申辰等另有拱局解释，不能把任意缺一字统一处理。半合之名不是量化比例；是否合化以及作用强弱，应结合月令、透干、根气、位置与冲破判断，本库不提供数值权重。

### 三会局（方局）
- 寅卯辰会东方木局
- 巳午未会南方火局
- 申酉戌会西方金局
- 亥子丑会北方水局

三会局以三字全见为形式条件；部分流派重视方局气势，但不能无条件断言三会一定强于三合，成化与强弱仍须审查全局。

### 六合
子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合火（或合土，有争议）

### 相刑
- 寅巳申三刑（无恩之刑）
- 丑戌未三刑（持势之刑）
- 子卯相刑（无礼之刑）
- 辰辰自刑、午午自刑、酉酉自刑、亥亥自刑

### 相害（相穿）
子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害

## 十神定义及生克关系

### 十神推导规则
以日干（日主）为中心，根据其他天干与日干的五行生克关系及阴阳异同来确定十神：

| 关系 | 阴阳相同 | 阴阳不同 |
|------|---------|---------|
| 生我（我之母） | 偏印（枭神） | 正印 |
| 我生（我之子） | 食神 | 伤官 |
| 克我（克我者） | 偏官（七杀） | 正官 |
| 我克（我制者） | 偏财 | 正财 |
| 同我（同类） | 比肩 | 劫财 |

### 十神详解

| 十神 | 含义 | 代表人事 |
|------|------|---------|
| 比肩 | 同我者，阴阳相同 | 兄弟、朋友、同辈、竞争者 |
| 劫财 | 同我者，阴阳不同 | 姐妹、竞争对手、损财者 |
| 食神 | 我生者，阴阳相同 | 子女（女命）、才华、口福 |
| 伤官 | 我生者，阴阳不同 | 子女（女命）、才艺、叛逆 |
| 偏财 | 我克者，阴阳相同 | 偏财、父（男命）、情人 |
| 正财 | 我克者，阴阳不同 | 正财、妻（男命）、稳定收入 |
| 偏官（七杀） | 克我者，阴阳相同 | 偏权、压力、小人之类 |
| 正官 | 克我者，阴阳不同 | 正权、上级、夫（女命） |
| 偏印（枭神） | 生我者，阴阳相同 | 偏学术、继母、孤独 |
| 正印 | 生我者，阴阳不同 | 母亲、学业、贵人 |

### 五行生克
- 相生：木→火→土→金→水→木
- 相克：木→土→水→火→金→木
