# 八字工作流与计算口径

## 收集最小信息

只收集问题、生日、明确的公历或农历（闰月标记）、出生钟点或时辰、出生城市、时间口径。姓名、曾用名、详细地址均非排盘必需，不主动索取。大运顺逆需要传统规则中的男/女参数，说明这只是该规则的输入，不是性别身份判断；不愿提供则省略大运，不能替用户猜。

已有信息不重复问；把独立的缺失问题放在一组询问。不要把收集表单变成十几轮盘问。生日、历法与时间口径确认后，调用 `scripts/bazi.py`，实际 stdout 才是盘面，禁止脑补日柱与神煞。

## 计算范围

- 默认：北京时间固定 UTC+08:00 的钟表时间，不自动处理历史中国夏令时、海外当地时或真太阳时。
- 年柱：以立春为界；月柱：十二节为界，而不是农历初一。
- 日界：23:00 起使用次日干支；00:00–00:59 使用当前公历日干支。这是明确选定的口径，不意味着所有流派一致。
- 子时只给地支而没有钟点：按早子时处理，同时保留歧义警告；不能说已经确定晚子换日。
- 公农换算使用 `lunar-python==1.4.8` 的独立农历实现，闰月为明确输入；旧内核朔/中气置闰逻辑不参与统一入口。日期跨度支持1900–2100。节气仍为简式近似，分钟级临界应交叉核验，不能把实现标成官方历书。
- `--place` 仅展示出生城市并提醒边界风险，不做经度、均时差或地理时区自动转换。
- 不知道时辰：输出年、月、日与未知时柱。历法计算可能以正午作内部占位，正午不是推断出的出生时间；节气交界日的年/月柱以及起运年龄保持待核验，不能固定个人完整八字。
- 起运采用三天折一岁与年干阴阳配合传统男/女参数。展示年龄区间会取整，含月份起运不能拿整数区间当精确交运日期。
- 农历生日保留是否闰月；本版回归覆盖2020闰四月、2025闰六月和民用日转换。同日节气与朔、2033/2034等特殊情况仍可用独立历书核验；公历出生证明优先，不能压过现实记录。
- `--as-of` 和用户主动声明的 `--deceased-year` 必须在1900–2100，不能早于出生，逝世年份不能越过分析截止；不主动询问逝世状态。

## 命理解释顺序

1. 展示出生输入、规则、盘面、警告和脚本版本。
2. 日主与月令：说明得令、通根、透干与支持/克泄耗关系；不能靠出现次数直接判身强身弱。
3. 十神与藏干：对照 [五行与十神表](wuxing-tables.md)，分别解释功能与关系，不把六亲称谓当现实人物命运。
4. 五行与格局：区分旺衰、调候、格局等论述视角。用神不是唯一事实；有分歧要写出哪条规则造成。
5. 大运与流年：只能解读真正算出的干支。时间窗口是文化框架，不是保证发生的事件。
6. 神煞：对照 [神煞表](shensha-table.md) 解释已算条目，不把凶煞解成疾病、死亡、犯罪、灾祸的预言。
7. 落到现实：结合用户已提供的具体问题提出可选择行动，解释何时该用现实证据替代象征判断。

## 经典材料的使用

[classical-texts.md](classical-texts.md) 是《穷通宝典》《三命通会》《滴天髓》《渊海子平》《千里命稿》《协纪辨方书》《果老星宗》《子平真诠》《神峰通考》的规则摘要，不是九部古籍全文。只说“调候原则”“格局视角”等，未核验原典章节时不能编造引文页码，也不能假装逐部阅读全文。

用户可主动对照个人经历，但禁止冷读式逼问、诱导回忆、反复调整断语以伪装准确率。不要宣称识破前世、附体、诅咒，也不卖改运产品。

## 输出契约

统一结构：**已知与缺失 → 规则 → 盘面 → 解读及依据 → 现实行动 → 不确定性**。

没有数据就讲知识，不硬排盘；没有充分时间资料就给能确定的部分，不用完整八字样式掩盖未知。健康、投资、法律、考试录取、伴侣忠诚等结果均不能由盘面证明。
