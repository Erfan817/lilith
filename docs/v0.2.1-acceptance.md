# v0.2.1 修复验收清单

基线：`a2e6c5e759e53e0ccd7a5755788f3ae2ad2bdbac`（v0.2.0）。本轮只修计算边界、资料一致性、宿主证据和跨平台兼容，不增加奇门/紫微排盘。

| 用户问题 | 验收要求 |
|---|---|
| 流年遗漏立春 | 2024-01-15与02-03为癸卯，02-05为甲辰；已知/未知生时同口径；02-04仅日期保留候选；明确偏移时刻在库交节秒切换；出生前精确截止拒绝，逝世年域从实际出生裁剪，UTC+14日期翻转比较绝对瞬间 |
| 大运与月份资料 | 起运不四舍五入，保留年月日时与交运瞬间；虚岁标签区别周岁；节令月不按农历初一 |
| 模糊出生描述 | 天刚亮/吃早饭只作追问线索，未经用户确认不输入确定时辰；仅时辰仍不输出确定起运 |
| 视太阳时自检 | 默认八字检查全部功能；civil只查历法/时区，apparent-solar另查astronomy-engine，缺依赖不可ready |
| 权重与经典引文 | 无可核出处的精确比例撤掉；原典短引有实际读过的篇章链接，流派与作者简化分开；未核原典不冒充直接引文 |
| 完整宿主流程 | 保存真实Hermes自然语言加载、补资料、工具计算、多轮更新、默认分享导出的结构化记录；记录实际失败，不以预计算模型解释冒充 |
| 来源路径 | JSON source_manifest恒为POSIX斜线，PureWindowsPath回归与WindowsCI验证 |
| Windows CI | 原生windows-latest与Ubuntu执行全套；不伪造Windows本地实测 |
| POSIX权限断言 | 0600模式只在POSIX检查；Windows仍运行内容、注入、覆写和报告CLI测试 |
| symlink测试 | 只在确实创建链接后验拒绝；不支持环境skip，不改报告防护 |
| 窄范围权限 | sources/report统一CLI放行，location联网不在自动权限名单；不开放任意Python或shell |
| description | 单行真实YAML标量，中文正负触发内容保留，官方规范验证 |
| Windows ACL措辞 | code/SKILL/README明确POSIX0600与Windows依赖目录ACL，不承诺Windows模式位私密 |

最终测试、远端提交和CI证据单独保存。未执行的宿主标未验证；Hermes权限不等同于Claude allowed-tools匹配与人工点击批准。
