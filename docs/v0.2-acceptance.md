# v0.2 验收范围

固定基线：`479bf05d0738d00a1b294499af6343f9f2f12d45`。本次保持一个根技能，不拆出相互依赖的技能。

| 评审项 | 验收要求 |
|---|---|
| 中文触发 | description 含真实中文术语与触发/负向场景；1–1024字符；元数据路由和宿主发现区分验证 |
| 安全问题输入 | 原问题不得插进shell单引号模板；UTF-8文件/标准输入；默认不回显；明确宿主日志与临时文件风险 |
| 宿主兼容 | 入口使用命令内容，不强制 Hermes工具名；说明Claude/Hermes/Cursor映射；安装依赖自检 |
| 标识 | `name`与安装目录 `lilith-diviner`一致，README安装/升级说明统一 |
| 标准字段 | required只name/description；compatibility≤500；可选license/metadata/allowed-tools；扩展不当通用必需 |
| 统计 | 实际扫描生成stats；历史验证数据明确版本，不能冒充实时数量 |
| 来源 | 六清单统一schema，url/title/访问精度/检索结果；历史日期不补造时间点，失败/partial不冒充完整阅读 |
| 入口自包含 | SKILL直接给环境检查、命令、安全执行；README负责人的安装和演示 |
| 权限 | 窄范围allowed-tools，权限受宿主与组织规则限制，不宣称每次免确认 |
| 评测 | 中文正负案例及断言；离线条目检查与真实模型/宿主验收分开 |
| 上下文 | 来源只按query小批读取，知识只读当前小节；不声称所有文件<1000 tokens |
| 八字 | 替换生产节气近似路径，独立交节黄金例、时区/DST、未知时刻/交界候选；vendor原字节保留 |
| 人设 | 莉莉丝的语气、深浅、尊重反例、错误先告知都有具体可执行约束 |
| 分享 | 可选离线HTML/SVG，只展示真实计算；默认去掉输入问题与生日时地，分享前预览 |

不把本版扩成全流派软件：奇门/紫微仍只解读可信外部盘；Placidus、交点/凯龙、组合盘、次限/返照仍未实现。城市自动查询需网络和来源许可；查询失败先告知并保留手动输入，不静默猜坐标。
